[9/8/2026 2:54 PM] Hannaneh Gh: # Bitcoin Price Tracker 💰

A simple Python script that fetches the real-time Bitcoin price (USD) using the free [CoinGecko API](https://www.coingecko.com/en/api).

## Features

- Fetches live Bitcoin price in USD
- Handles network errors and timeouts gracefully
- Clean, well-commented code
- Cross-platform (fixed Windows console encoding issue for non-English output)

## Tech Stack

- Python 3
- [requests](https://pypi.org/project/requests/) library
- [CoinGecko API](https://www.coingecko.com/en/api) (no API key required)
